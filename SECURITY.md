# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories. If you
cannot use GitHub, email <security@secpal.app>. A PGP key is available on request.
[Report a vulnerability](https://github.com/SecPal/contracts/security/advisories/new)

Include the affected contract revision or component, steps to reproduce the
issue, and its potential impact. Use the private channel for coordinated
disclosure.
